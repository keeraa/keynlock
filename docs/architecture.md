# Архитектура KEYNLOCK

В репозитории есть основная игра и несколько 3D-приложений. У каждого свой вход, набор проверок и процесс сборки. Перед правкой определите, в каком приложении виден результат.

## Где работать

| Участок | Исходники | Что здесь менять |
| --- | --- | --- |
| Основная игра | [index.html](../index.html), [js/](../js/README.md), [css/](../css/README.md) | Кампания, миссии, инвентарь и головоломки. Общие сервисы новых модулей идут через [js/modules/runtime.mjs](../js/modules/runtime.mjs). |
| Логово | [js/3d/scenes/lair](../js/3d/scenes/lair/README.md) | Геометрия комнаты, свет, прогулка, камера и вход в мастерские. |
| Ателье и алхимия | [js/3d/workshops](../js/3d/workshops/) | Механики, интерфейс и сохранения каждой мастерской. Эти же пакеты запускаются самостоятельно и встраиваются в Логово. |
| Игровой мир | [js/3d/scenes/city](../js/3d/scenes/city/README.md) | Город, ландшафт, дома, дорожная сеть и [редактор карты](../js/3d/scenes/city/path-builder/README.md). |
| Архив ключей и Мастерская ключей | [key-archive](../js/3d/scenes/key-archive/README.md), [key-forge](../js/3d/scenes/key-forge/README.md) | Игровой цикл Архива и редактор ключей соответственно. В обоих проектах `dist/` содержит отслеживаемые исходники статического сайта. |
| Верстак и лаборатория замков | [workbench](../js/3d/scenes/workbench/README.md), [locks](../js/3d/scenes/locks/README.md) | Отдельные проекты для сборки механизмов и моделирования замков. Верстак в Логове пока подключён отдельным статическим документом. |
| Общий 3D-код | [js/3d/core](../js/3d/core/) | Контракт хоста, переводчик, переиспользуемые функции камеры и рендеринга. |
| Общие ключи и материалы | [shared/keys](../js/3d/shared/keys/README.md), [shared/materials](../js/3d/shared/materials/README.md) | Канонические исходники для сцен, перечисленных в реестрах. Копии для статических приложений обновляются скриптами синхронизации. |

## Границы зависимостей

- Основная игра и 3D-приложения запускаются независимо. Общий 3D-код в `core/` не импортирует конкретную сцену или мастерскую.
- Логово отвечает за комнату, общую камеру, ввод и рендерер. Мастерская отвечает за свои правила и состояние. Во время игры они обмениваются сервисами через [контракт хоста](../js/3d/core/host/workshop-host.js).
- Пакеты Ателье и алхимии экспортируют две точки входа. `/embedding` предоставляет интерфейс и отложенный запуск приложения, `/room-assets` — ресурсы и настройки, нужные комнате. Логово импортирует эти точки вместо внутренних файлов пакетов. ESLint проверяет это правило для кода Логова. Тесты, которым нужен доступ к внутренней механике, используют явные относительные пути.
- Камера и ввод в Логове переключаются через [camera-input.js](../js/3d/scenes/lair/src/navigation/camera-input.js). Покадровая последовательность находится в [lair-frame-loop.js](../js/3d/scenes/lair/src/lair-frame-loop.js). Камеры отдельных приложений продолжают работать локально.

## Как запустить и проверить

Команды выполняются из корня репозитория.

| Приложение | Запуск | Проверка |
| --- | --- | --- |
| Основная игра | `npm run dev` | `npm test` |
| Логово, Ателье, алхимия | Один раз `npm ci --prefix js/3d`, затем `npm run dev:lair`, `npm run dev:atelier` или `npm run dev:alchemy` | `npm run check:3d-workspace` |
| Игровой мир | `npm --prefix js/3d/scenes/city run build`, затем открыть `path-builder/` на HTTP-сервере из `scenes/city/dist` | `npm --prefix js/3d/scenes/city run check` |
| Архив и Мастерская ключей | Поднять HTTP-сервер из `dist/` нужного приложения | `npm --prefix js/3d/scenes/key-archive test` или `npm --prefix js/3d/scenes/key-forge test` |
| Верстак | Поднять HTTP-сервер из `js/3d/scenes/workbench/public` | `npm --prefix js/3d/scenes/workbench run check` |
| Лаборатория замков | `npm ci --prefix js/3d/scenes/locks`, затем `npm --prefix js/3d/scenes/locks run serve` | `npm --prefix js/3d/scenes/locks run release:check` |

`check:3d-workspace` запускает проверки типов, линтер, тесты и проверку геометрии Логова, уникальности исходников мастерских и тесты Ателье. Браузерные тесты Логова запускаются отдельно.

```sh
cd js/3d
npx playwright install chromium
npm run test:browser -w keynlock-lair
```

Опубликованные сцены перечислены в [реестре](../js/3d/SCENES.md). Логово и Игровой мир публикуются в Sites из GitHub `main` по отдельным инструкциям. [Логово](../js/3d/LAIR-RELEASE.md) · [Игровой мир](../js/3d/WORLD-MAP-RELEASE.md)
