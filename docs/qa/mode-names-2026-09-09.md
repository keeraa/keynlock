# Собственные названия головоломок · 2026-09-09

Обновлены каталог, регистрация механик, файлы JS/CSS, DOM-идентификаторы,
ссылки на изображения, сюжетный маршрут и проверки. 28 механик и 70 вариантов
заданий сохранены. Алгоритмы и баланс не изменены.

| Идентификатор | Название |
| --- | --- |
| keyprofile | Слепок скважины |
| turnmemory | Память поворотов |
| workingangle | Рабочий угол |
| signalbalance | Баланс сигналов |
| pinflight | Штифтовый замок |
| springtumblers | Подпружиненные тумблеры |
| pairednodes | Парные узлы |
| wharf | Задвижки набережной |
| ringsecret | Кольцевой секрет |
| cylinderpath | Ход цилиндра |
| soundlatch | Звуковой зацеп |
| torqueangle | Угол натяжения |
| ringpassage | Кольцевой проход |
| twinbalance | Двойное равновесие |
| timingneedle | Точная остановка |
| symbolpins | Символьные штифты |

SaveStore schema 2 переносит старые идентификаторы в текущем сохранении,
вложенных слотах и импортируемых резервных копиях. Переносятся сложности,
пройденные задания, шаги и сцены сюжета, отметки разовых наград, прогресс
выпадения рукояток. Уже существующий новый ключ имеет приоритет при совпадении.
Сторонние ключи localStorage и свободный текст не переименовываются.
Старые идентификаторы оставлены только в таблице совместимости SaveStore и
тестовых данных. Исторические QA-отчёты могут описывать старые названия.

Проверено локально, до фиксации commit:

- `npm test`: сценарии игры и миграция старых сохранений, слотов, импорта,
  работа при переполненном хранилище и повторная запись после восстановления.
- `npm run build`: сформирован манифест 572 изображений с новыми путями.
- Изолированный Chromium, без звука: 70/70 запусков через API миссий успешны,
  зарегистрированы обработчики всех 28 механик, 28/28 превью отвечают HTTP 200.
- Старое сохранение в браузере: выбранная механика, сложность, пройденные
  задания, разовый бонус и счётчик гарантии рукоятки перенесены.
- 1280×720: открыта «Память поворотов», интерфейс и изображения отображаются;
  новые названия видны в журнале. Ошибок JavaScript не зарегистрировано.

Проверка запусков не является полным прохождением всех головоломок.
