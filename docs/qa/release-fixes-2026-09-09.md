# Исправления R01–R03 — 2026-09-09

Статус: реализованы и проверены локально. Публикации не было.
Основание: [аудит релиза](release-readiness-2026-09-09.md).

## R01: доступность действий алхимии

Стойка металлов скрыта только на вкладке «Пигменты», где используется отдельная
палитра. На «Смешении» стойка снова видна. Панель пигментов не наследует смещение
стола других станций, имеет ограничение по высоте и прокрутку; внутренние блоки
не сжимаются так, чтобы выталкивать нижние действия за панель.

В отдельной Chromium-сессии `release-fixes` проверены 1280×720, 900×844,
1440×900, 1920×1080 и дополнительно 390×844. При 1280×720 центр кнопки возвращает
`pigmentCheck` через `elementFromPoint`; реальный клик проходит. В узких окнах
после прокрутки кнопка остаётся внутри экрана и доступна. Это проверка вкладки
пигментов, не приёмка всех мобильных экранов.

## R02: проверка результата

Успех определяется равенством вычисленных цветов, показанных в карточках,
а не совпадением скрытого списка ингредиентов. Пустая смесь не проходит.
Тесты покрывают один и несколько одинаковых пигментов, перестановку ингредиентов,
другие пропорции и заведомо разные цвета.

В браузере создан воспроизводимый образец из двух красных порций, положена одна
красная. Цвет обеих карточек `rgb(239, 59, 59)`. Реальный клик дал «Точный оттенок
получен». Для этого теста генератор случайности временно фиксировался и был восстановлен.

## R03: отказ хранилища

SaveStore поддерживает копию текущих данных в памяти, сохраняет доступный старый
сейв даже при переполненном localStorage на старте и перехватывает ошибки чтения,
записи и удаления. `persistent` отражает текущее состояние, а не только начальное.

При отказе видна постоянная панель с объяснением, скачиванием копии и повторной
записью. Слоты обозначаются как временные; загрузка временного слота не перезагружает
страницу и не теряет его. При восстановлении записи записываются накопленные
изменения и удаления. Есть запрос браузера перед уходом со страницы с временными
данными (показ зависит от правил браузера и взаимодействия пользователя).

В настройках можно скачать JSON-копию и загрузить её обратно с подтверждением
замены прогресса. Неподдерживаемый формат отклоняется без изменения данных.
При ошибке записи импорт не вызывает перезагрузку: текущий прогресс возвращается
в память для скачивания. Постоянное хранение не обещается, пока ошибка не устранена.

Браузерная проверка: принудительный `QuotaExceededError` → запись 123 монет в
память → видимая панель → скачивание файла с 123 монетами → восстановление
обычной записи → повтор → localStorage содержит 123 → загрузка скачанной копии
через выбор файла и подтверждение → перезагрузка → 123 монеты, «Продолжить» активно.
Неверный файл отклонён; монеты остались 123. Пользовательский профиль не использовался.

Модельные проверки дополнительно покрывают запрет хранилища на старте, отказ
чтения во время игры, старые данные при переполнении, удаление ключей, повторную
попытку, перезагрузку и чтение изменений из другой вкладки.
