# Полная загрузка перед игрой · 2026-09-09

Меню становится доступно только после скачивания всего списка изображений
из `asset-manifest.json` и всех звуков из `KeynlockAudioAssets`.
Отложенный запуск с загрузкой только оформления меню отменён.

Текущий список содержит 572 изображения (167,25 MiB на диске), включая
реставрационную галерею. Звуки скачиваются полностью, а не до события
`canplaythrough`. Манифест читается заново; ресурсы запрашиваются с
`cache: force-cache`. В опубликованной версии действует HTTP-кеш ассетов,
заданный в `vercel.json`. Локальный dev-сервер намеренно отдаёт `no-store`.
Это предварительное скачивание, а не отдельный режим офлайн.

Файлы загружаются четырьмя параллельными запросами. Тела ответов читаются до
конца; картинки не декодируются все одновременно, чтобы галерея не занимала
сотни мегабайт распакованной графики. Браузер декодирует изображение при показе.

Каждый запрос ограничен 30 секундами. При ошибке меню остаётся закрытым,
появляется кнопка «Повторить загрузку». Повторяются только неудачные файлы.
Ошибка или таймаут манифеста также позволяют повторить запрос.
Готовность DOM гарантирует, что быстрый кеш не опередит регистрацию меню.

Проверено:

- `npm test`: все игровые сценарии и тест полной загрузки прошли.
- Тест загрузчика проверяет галерею, все звуки, ожидание полного тела ответа,
  очередь из четырёх запросов, таймаут, запрет преждевременного старта,
  повтор только недостающих файлов и готовность скриптов.
- Изолированный Chromium, локальный сервер: прогресс 100%, меню видно,
  кнопка повтора скрыта, ошибок JavaScript нет.

Изменение пока локальное. Замер 47 секунд против 5 секунд относился к
отменённому варианту запуска и больше не описывает текущую реализацию.
