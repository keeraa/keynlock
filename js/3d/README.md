## Принцип подключения

- Каждая сцена владеет своими 3D-объектами, событиями и их освобождением при выходе.
- Общие камера, рендерер, освещение и эффекты выделяются после переноса остальных сцен.
- Инвентарь, прогресс миссий и награды остаются единственным источником данных в `js/world/` и `js/core/`.
- Старые страницы не переписываются разом: переход через адаптер сцен после отдельной проверки.

Текущая реставрация содержит свой Vite-проект для самостоятельного запуска. Её `src/`, `public/`, тесты и зависимости сохранены вместе, без опубликованных Site-ключей и конфигурации хостинга.
