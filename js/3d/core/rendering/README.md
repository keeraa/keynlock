# KEYNLOCK · общий 3D-рендеринг

`painted-texture.js` подготавливает одинаковые CanvasTexture для рисованных покрытий: 512px, sRGB, mirrored repeat, anisotropy 4. Он не меняет пигмент и не выбирает способ обводки.

Режимы остаются независимыми:

- **locks:** `scenes/locks/src/js/effects/painted-pigment.js`, `cartoon-filter.js` — исходный пигмент и экранный контур.
- **alchemy:** `scenes/alchemy/src/visuals.js` — собственные палитры, toon и контурная геометрия.

Сборки включают общий JS-модуль внутрь автономных пакетов сцен: locks — через esbuild, alchemy — копированием в `dist/shared/`. Это позволяет публиковать сцены отдельно, без сетевых импортов.

При последующей унификации алгоритмов обязательно сравнивать визуальный результат каждого режима.

## Размытие фона

`background-blur.js` содержит два независимых GLSL-ядра с общей системой режимов:

- `background` — девять выборок уже отрисованной комнаты в алхимии; сохранён кеш статического слоя, а преломление колб выполняется отдельным проходом.
- `depth` — пять выборок с проверкой глубины в реставрации; сохраняются настройки фокуса и эффект при смене ракурса.
- `off` — оба режима могут быть отключены настройками сцены.

Настройки в `BLUR_PRESETS` совпадают с предыдущими значениями сцен. Потребитель отвечает за WebGLRenderTarget, camera и вызов прохода; модуль не меняет обработку стекла или геометрию картин.
