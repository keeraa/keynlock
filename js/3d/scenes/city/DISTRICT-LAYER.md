# KEYNLOCK — зонирование городской карты

Слой районов использует данные [js/district-zoning.js](js/district-zoning.js) и утверждённые цвета/названия из [js/world-data.js](js/world-data.js) и `js/data/world.js`.

| 01 | Старый квартал | восток южного берега | старые улицы, жилые дома, лавки |
| 02 | Порт | западные берега главной реки | склады, причалы, торговля |
| 03 | Район искусств | центральная южная часть | музей, галереи, театр |

| 06 | Верхний город | северо-восток | особняки, сады, состоятельные кварталы |

Вода — самостоятельная часть географии. Внутренних стен районов нет. Слой выполняет только визуальную функцию и не меняет рельеф, дороги, сохранения, мосты или дома.

## Модуль слоя

`js/district-layer.js` предоставляет `createDistrictLayer({host, project, heightAt, dimensions, onSelect, initiallyVisible})`.

- `host`: DOM-контейнер игрового 3D-канваса (наложение рисуется поверх WebGL).
- `project({x,y,z})`: преобразование мировой точки в пиксели контейнера `{x,y,visible}`, например, через `THREE.Vector3.project(camera)`.
- `heightAt(x,z)`: высота земли в данной точке.
- `dimensions`: размеры территории в метрах, по умолчанию 2640 × 1800, и, при необходимости, `flipX`/`flipZ` для ориентации осей.
- `onSelect(id)`: выбор района для фокуса камеры или карточки.

`overlay.update()` вызывается при изменениях камеры; `setVisible(bool)` переключает заливку и подписи, `setOpacity(0..1)` меняет прозрачность, `destroy()` очищает DOM. Переключатель и список районов создаются автоматически. Новых 3D-полигонов нет.
