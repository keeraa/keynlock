# Архитектура архива ключей

`dist/js/main.js` — точка входа и координатор игрового процесса: ввод, режимы, взаимодействия, звук, кадры. Новые обязанности следует выносить в профильные модули.

| Модуль | Ответственность |
| --- | --- |
| `rules.js` | Состояние и игровые правила; без DOM и Three.js |
| `archive-persistence.js` | Чтение, миграция и запись сохранений и визуальных настроек |
| `archive-bath-progress.js` | Постоянные полосы над тазиками: проекция в экран для WebGL и Canvas, готовность по индексу ключей без секунд и подписей |
| `archive-hud.js` | Счётчики, инвентарь и кэш миниатюр ключей |
| `visual-panel.js` | Единое актуальное состояние ползунков, переключателей и применение к миру |
| `player-movement.js` | Ходьба, столкновения и покачивание камеры |
| `world.js` | WebGL-мир: сборка компонентов, игровой цикл сцены, синхронизация ключей |
| `world-architecture.js`, `world-cabinet.js` | Геометрия зала и шкафов |
| `world-materials.js`, `world-lighting.js`, `world-particles.js` | Материалы, люстры и декоративные частицы |
| `key-hover-material.js` | Отдельный шейдер подсветки ключа |
| `fallback-world.js` | Аварийная 2D-сцена при недоступности WebGL |
| `fallback-surfaces.js` | Рисованные поверхности резервной сцены |
| `key-factory.js`, `key-provider-entry.js` | Адаптеры и построение моделей ключей |
| `visual-settings.js`, `painted-renderer.js`, `painted-shader.js` | Настройки и независимые GPU-проходы мультяшного света и контурной обводки |
| `performance-hud.js`, `geometry-stats.js` | CPU/FPS, вызовы отрисовки и кэш счётчика геометрии |
| `cabinet-completion.js` | Завершение видимых рядов и шкафов, волна, вспышка и состояние свечения; общий для WebGL и Canvas |
| `key-index.js` | Поиск ключей по ID и пространственным ячейкам |

Основной мир и резервный мир реализуют общий контракт, вызываемый из `main.js`: `camera`, `bounds`, `setVisualSettings`, `renderer.render`, `refreshHand` и игровые методы взаимодействия. Изменения этого контракта должны сохранять оба варианта рендера.

Сохранения остаются совместимыми с прежними ключами localStorage и миграциями. Геометрия и материалы ковра и ключей в этом рефакторинге не менялись. Метрики CPU измеряют нагрузку JS + синхронного вызова рендера, а не время выполнения GPU; для GPU нужны отдельные таймеры WebGL.

Мультяшный свет и контурная обводка выполняются отдельными GPU-проходами. Полноэкранная имитация гуаши удалена: гуашевая живопись задаётся материалами отдельных объектов. Каждый проход проверяет результат в `WebGLRenderTarget` при включении и изменении настроек. Если один проход выдаёт ошибку или пустой результат, только он временно отключается: другой продолжает работать. После изменения настроек проверка повторяется. В строке «ВИЗУАЛ» можно навести указатель и увидеть состояние каждого прохода. Чтение пикселей экранного буфера не используется из-за ложных срабатываний в некоторых браузерах. При недоступности WebGL остаётся резервный Canvas 2D.

Проверки: `npm test`. Тесты модулей находятся в `tests/`.

Праздничные эффекты шкафов запускаются после завершения полёта последнего
ключа в ячейку. Начальная загрузка устанавливает состояние без повторной
вспышки; заполненный шкаф сохраняет мягкое свечение эмблемы. Учёт рядов
обновляется при игровых действиях, в кадре вычисляются только короткие эффекты.
Воздушная перспектива выполняется внутри существующего прохода дальней
мягкости: от 10 до 42 м снижаются насыщенность и контраст, с отдельным
цветом воздуха для дневного и ночного режимов. Ближняя зона остаётся чёткой.
