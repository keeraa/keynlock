# Архив ключей — следующие механики

Зафиксировано 2026-11-20. Ориентир — A Place for Every Potion: спокойная уборка без таймера, где всё понятно с первого взгляда и не нужно рассматривать каждый ключ.

## 1. Ключ в воске

- Новое состояние ключа: `wax`, по аналогии с `mud` и `rust`.
- Ключ в воске видно издалека: толстый светлый наплыв воска поверх ключа.
- Чтобы очистить, ключ подносят к свече и держат несколько секунд. Воск тает, ключ становится чистым или переходит в следующее загрязнение, если их несколько.
- Ключ в воске нельзя повесить в шкаф, пока не растоплен воск. Подсказка: «Ключ в воске · растопи у свечи».
- Воск растапливает **любая горящая свеча**. Свечи в центре зала нет.
  - С самого начала горит одна свеча на столике у входа.
  - Потом подходят и свечи у собранных шкафов (см. п. 3), они загораются по мере уборки.

## 2. Шкатулки — «мистери-бокс»

- По залу лежат шкатулки. Их находят так же, как ключи: на полу, под мебелью, в углах.
- Шкатулку открывают взаимодействием (`E`). Внутри **10 случайных ключей**, они высыпаются на пол рядом.
- Случайные ключи могут быть любого семейства и в любом состоянии (чистые, грязные, ржавые, в воске, сломанные).
- Связи с миссиями основной игры **нет**: шкатулки просто находят.
- Результат должен быть детерминированным и сохраняться: при перезагрузке содержимое шкатулки не меняется. Удобно выбирать ключи по сиду от id шкатулки.
- Откуда берутся ключи для шкатулок, решим и внедрим позже. Ограничение: сейчас ровно 100 ключей на семейство и 96 мест в шкафу (4 сломанных переплавляются), так что лишние ключи переполнят шкафы.

## 3. Свечи у шкафов

- У каждого шкафа две свечи: слева и справа.
- Пока шкаф не заполнен, свечи не горят.
- Когда шкаф собран полностью (`sorted[type] === required[type]`), обе свечи загораются: тёплое пламя, мягкое свечение, звук `finish`.
- При загрузке сохранения свечи у уже собранных шкафов сразу горят.
- Если снять ключ из собранного шкафа, свечи гаснут.
- Должно работать в обоих рендерах: WebGL и Canvas.

## 4. Связка (покупается за металл)

- В руках, как сейчас, помещается **4 ключа** (`MAX_HELD = 4`).
- Связка стоит **15 металла**. Металл дают сломанные ключи в плавильне (всего 40 на игру).
- **Одна связка = 4 ключа** одного семейства. Лимит в руках не растёт: те же 4 ключа, только собранные в связку.
- Связку вешают в шкаф одним нажатием: все 4 ключа занимают ближайшие свободные места.
- Ещё не решено: собираются ли ключи в связку автоматически при подборе.

## Затрагиваемые модули

| Механика | Где |
| --- | --- |
| Состояние `wax`, шкатулки, связки, металл | `js/rules.js` (модель, `validateState`, миграция сохранений), `js/archive-persistence.js` |
| Действия игрока | `js/archive-actions.js` |
| Подсказки | `js/archive-interaction-prompts.js` |
| Свеча у входа, наведение на свечи и шкатулки | `js/archive-surface-aim.js`, `js/interaction-range.js` |
| Свечи у шкафов | `js/world-cabinet.js`, `js/world.js`, `js/fallback-canvas-architecture.js` |
| Вид воска на ключе | `js/key-instance-finish.js`, `js/key-dirt.js`, `js/fallback-canvas-keys.js` |
| Шкатулки в зале | `js/world.js`, `js/fallback-world.js`, `js/fallback-canvas-renderer.js` |
| Интерфейс связок и металла | `js/archive-hud.js`, `index.html`, `styles.css` |

Исходники в `js/` и опубликованная копия в `dist/js/` сейчас идентичны; тесты импортируют `dist/js/`. Изменения нужно вносить в обе папки.
