# KEYNLOCK · Логово команды

Интерактивный 3D-прототип центральной комнаты с двухсветным потолком. Реставрация с двумя мольбертами «Смерть Сарданапала», красками и охристой стеной ателье расположена вдоль левой стены. Алхимия развёрнута к правой стене с оригинальной зелёной гуашевой плиткой, рецептом, часами, цветными пигментами и семью подписанными реагентами. Штаб — по центру, верстак — справа, граммофон сохраняет музыкальную идею лора.

За основу взяты материалы и визуальные решения текущих мастерских KEYNLOCK. Столешницы, пол и остальное дерево используют уже существующие широкомазковые гуашевые текстуры алхимии. Картины, фактуры, этикетки реагентов и палитра плиток повторно используются из исходного репозитория.

Большая общая Three.js-комната служит точкой входа. Реставрация и алхимия используют свои исходные модели и механики непосредственно внутри этой комнаты, с одним WebGLRenderer. Верстак пока открывается во встроенном документе. Исходные мастерские продолжают существовать отдельно; изменения в их Site переносятся в логово через обновление исходников и новую сборку.

- **Реставрация:** полное [исходное Ателье](https://atelier-restoration-1115.k1r11111.chatgpt.site/) со всеми картинами, настройками, пятью инструментами и сохранениями. Перед возвратом в логово активная картина гарантированно сохраняется через подтверждение от оригинального приложения; стена в Логове синхронизируется через отдельный мост.
- **Алхимия:** полная [исходная лаборатория](https://keynlock-alchemy-lab-1115.k1r11111.chatgpt.site/) перенесена в `integrations/alchemy/` и запускается через `src/alchemy-in-room.js`. Сохранены 3D-модели, перенос реагентов, анимированная физика жидкостей, рецепты и визуальные настройки. Камера и симуляция подключены к миру логова; при выходе симуляция приостанавливается. Текстуры и логика остаются исходными.

  В `integrations/alchemy/src/look/` выделены переносимые модули света (`alchemy-look.js`) и гуашевых фильтров (`alchemy-filters.js`). Точные параметры оригинальной лаборатории экспортируются как `ALCHEMY_LOOK`. Панель настроек находится отдельно в `src/ui/visual-panel.js`. Общая комната пока использует собственные настройки освещения; профиль алхимии подготовлен для её будущего переключателя.
- **Верстак:** полный [исходный верстак](https://keynlock-workbench-1116.k1r11111.chatgpt.site/) — изготовление ключа, сборка штифтовых замков и песочница механизмов.

Техническое ограничение: при открытии зоны запускается отдельный WebGL-контекст исходного приложения внутри бесшовного экранного перехода. Полного объединения геометрии этих проектов в один общий `THREE.Scene` пока нет. В отличие от предыдущей версии, Логово не содержит упрощённых самостоятельных реализаций механик.

Запуск: `npm install && npm run dev`. Проверка: `npm run check && npm run build`.

Браузерные регрессии запускаются после установки Chromium командой `npx playwright install chromium`. Команда `npm run test:browser` собирает production-версию и проверяет переливание, паузу нагрева и сбой загрузки картины в отдельных сессиях браузера.
