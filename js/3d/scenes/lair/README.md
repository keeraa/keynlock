# KEYNLOCK — Логово

Актуальный исходный код центральной 3D-комнаты KEYNLOCK, сохранённый **17 ноября 2026 года**.

**[Открыть Логово](https://keynlock-lair-1116.k1r11111.chatgpt.site/)**

## Что входит

- Единая комната Three.js: штаб, реставрация, алхимический стол, верстак, граммофон и оформленная галерея живописи.
- Реставрационная мастерская из `integrations/atelier/`, подключённая непосредственно к комнате и общему WebGL-рендереру. Сохраняются её инструменты, картины и настройки.
- Галерея из 30 картин: загрузка изображений учитывается общим стартовым экраном; при просмотре стены размытие отключается.
- Перенесённые оригинальные версии алхимии и верстака в `public/stations/`. Они открываются внутри Логова, сохраняя свои механики.
- Гуашевые текстуры интерьера, освещение, эффекты и управление камерой; исправлены длинные диагональные тени.
- Тесты интеграции, геометрии, загрузки, галереи и управления.

## Разработка

```bash
npm install
npm run dev
```

```bash
npm run check
npm run build
```

Скрипт `build` сначала собирает ателье из `integrations/atelier/` в `public/stations/atelier/`, затем собирает Логово. Результаты сборки и временные файлы не включены в репозиторий.

Сцены алхимии и верстака сохранены локально, поэтому этот снимок репозитория не зависит от будущих публикаций отдельных прототипов. Ссылки на оригиналы и описание источников — в `integrations/ORIGINAL_SOURCES.md`.
