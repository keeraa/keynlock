# KEYNLOCK · Логово команды

Интерактивный 3D-прототип центральной комнаты. Реставрация находится слева у стены, штаб — по центру, верстак и алхимия — справа; граммофон сохраняет музыкальную идею лора.

За основу взяты материалы и визуальные решения текущих мастерских KEYNLOCK. Фотографии картин и фактуры дерева перенесены из существующего репозитория. Отдельные игровые сцены открываются ссылками из точек взаимодействия; встраивание их состояния и механик в единый игровой цикл — следующий этап.

Запуск: `npm install && npm run dev`. Проверка: `npm run check && npm run build`.
