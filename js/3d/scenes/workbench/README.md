# KEYNLOCK — 3D-верстак

Самостоятельная модульная версия 3D-мастерской на Three.js r187. Разделы: **01 Выпиливание ключа**, **02 Штифтовый механизм**, **03 Песочница механизмов**, **04 Кодовый замок**.

- Опубликованная сцена: https://keynlock-workbench-1116.k1r11111.chatgpt.site/
- Снимок исходников: `023222ed43b5ee354dfc65b55f0ebd9f3d51de59` (опубликованная версия от 17.11.2026).
- Точка входа: `public/index.html`.
- Three.js r187, локальные зависимости и текстуры; запуск без CDN.

Шкатулка в разделе 04 использует шестизначный код, видимый в меню. Цифры меняются кнопками ↑ ↓ на корпусе и в панели; совпадение открывает крышку с простым прямоугольником внутри. Сталь, латунные полосы, металлические кольца и кнопки используют общие гуашевые текстуры. История проверок отсутствует.

## Структура

- `public/` — полный запускаемый вариант сцены; `js/` содержит отдельные модули управления, геометрии, сборки, состояний и визуализации.
- `tests/` — 87 автоматических проверок логики и модулей, включая расширенные посадочные места, проектирование, сохранение и испытание.
- `scripts/build.mjs` — сборка статического `dist/` из `public/`.
- `mechanism-playback.js`, `mechanism-inspector.js`, `mechanism-thumbnails.js` — отдельно воспроизведение движения, панель свойств и снимки настоящих 3D-деталей.

## Чистка кода · 17.11.2026

1. Песочница 3D-деталей и её миниатюры создаются только при открытии раздела 03.
2. Фоновые циклы Three.js останавливаются в скрытых разделах.
3. Текстуры окрашенного металла загружаются один раз на тип материала и переиспользуются.
4. Отдельные модули отвечают за анимацию движения, инспектор и миниатюры.
5. Упрощены колёса кодовой шкатулки и обновление динамических данных инспектора.

Все 87 тестов и сборка прошли; визуальную приёмку приватного WebGL-прототипа проводим отдельно.

## Проверка и запуск

```bash
npm run check
npm run build
python3 -m http.server 8080 --directory dist
```

Затем открыть `http://localhost:8080/`.

Сборка и тесты запускаются из этой папки; внешние npm-зависимости не требуются. Изменение файлов в GitHub не обновляет опубликованную сцену автоматически.
