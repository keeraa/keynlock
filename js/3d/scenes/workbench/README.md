# KEYNLOCK — 3D-верстак

Самостоятельная, модульная версия сцены изготовления ключей, расширенной сборки замка и проектирования собственных четырёхканальных цилиндров.

- Опубликованная сцена: https://keynlock-workbench-1116.k1r11111.chatgpt.site/
- Снимок исходников: `c9c3f4adda05ecb52c3f3b5b9a5ced0c16116a82` (репозиторий публикации, 16.11.2026).
- Точка входа: `public/index.html`.
- Three.js r187, локальные зависимости и текстуры; запуск без CDN.

## Структура

- `public/` — полный запускаемый вариант сцены; `js/` содержит отдельные модули управления, геометрии, сборки, состояний и визуализации.
- `tests/` — 61 автоматическая проверка логики и модулей, включая расширенные посадочные места, проектирование, сохранение и испытание.
- `scripts/build.mjs` — сборка статического `dist/` из `public/`.

## Проверка и запуск

```bash
npm run check
npm run build
python3 -m http.server 8080 --directory dist
```

Затем открыть `http://localhost:8080/`.

Сборка и тесты запускаются из этой папки; внешние npm-зависимости не требуются. Изменение файлов в GitHub не обновляет опубликованную сцену автоматически.

Состояние механик и следующие шаги — [`docs/3d-workbench-roadmap.md`](../../../../docs/3d-workbench-roadmap.md).
