# KEYNLOCK — инвентаризация гуашевых материалов

Проверено дерево репозитория `keeraa/keynlock`, ветка `main` (18.11.2026).

- **45** канонических растровых материалов после инвентаризации (было 42, добавлено 15).
- Перенесены: 4 текстуры архива ключей; 3 породы дерева реставрации; 5 покрытий штифтов замков; 3 оригинальных PNG-варианта стекла из интеграции алхимии в логово.
- Изображения картин, этикетки алхимических колб, концепт-арты и орнаменты рукоятей остаются отдельными игровыми ассетами. Они не являются повторяемыми поверхностными материалами.
- Материалы в `js/3d/scenes/**` сохранены как совместимые копии для развёрнутых сцен. `sync.mjs --check` проверяет тождественность содержимого.

| Сцена | Итог |

| Город | Все растровые текстуры поверхностей в Git включены; концепт и схема районов исключены. |

| Замки | 5 покрытий штифтов включены; декор рукоятей исключён. |
| Верстак | Совместно используемые металлические и механические текстуры учтены; изображения вариантов рукоятей исключены. |
| Реставрация | 3 текстуры дерева включены; репродукции картин исключены. |

## Остаётся проверить отдельно

1. **Конструктор ключей**: отдельного каталога его исходников в этом дереве Git нет. Сверка опубликованной версии с библиотекой пока не выполнена.
2. **Процедурные материалы JS / Canvas**: `painted-texture.js`, генераторы металла, дерева и гуашевых мазков создают текстуры во время исполнения. Нужен отдельный этап унификации генераторов и их параметров.
3. **Новые изменения опубликованных Sites** могут опережать зафиксированные в Git изображения. Для абсолютной полноты требуется сверить актуальные развёрнутые сборки.

Источник истины для файловых текстур — `js/3d/shared/materials/manifest.json`.
