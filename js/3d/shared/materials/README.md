# KEYNLOCK · общая библиотека гуашевых материалов

Единый источник исходных растровых фактур для замков, верстака, алхимии, логова и города.

## Структура
- `metals/` — латунь, медь, эмаль, графит, сталь;
- `wood/` — дуб, орех, ясень; сохранены оригинальные и v2-варианты;
- `glass/` — стекло трёх стилей;
- `surfaces/` — пробка, обои ателье;
- `mechanisms/` — штифты, шестерёнки, механический блок;
- `architecture/` — штукатурка, камень, крыши, ставни, окна, мох и двери.

Каталог `manifest.json` хранит точный путь к оригиналу, SHA Git-блоба и список существующих потребителей. Всего **42 материалов**, версии не потеряны.

## Правило единого источника
1. Редактировать исходную текстуру только в `js/3d/shared/materials/<категория>/`.
2. Для обновления локальных копий сцен запускать `node js/3d/shared/materials/sync.mjs --sync` из корня репозитория.
3. Перед коммитом/сборкой проверять синхронизацию командой `node js/3d/shared/materials/sync.mjs --check`. Возврат ненулевого кода означает рассинхронизацию.
4. При добавлении текстуры включать её и все пути потребителей в `manifest.json`.
5. Публикуемые автономные сборки сохраняют фактуры в своих `assets/` — это производные копии. В будущих сборщиках копирование должно выполняться из этой библиотеки.

Сохранены все прежние версии материалов. Никакие файлы в работающих сценах в этом коммите не удалены; следующий переход — подключить `sync.mjs --check` к CI каждого пакета.
