# Общие рисованные материалы KEYNLOCK 3D

`metals/` — единый источник пяти идентичных гуашевых фактур, обнаруженных в сценах замков и алхимии.

Сборка замков копирует их из этой папки в собственный `dist/assets/`; опубликованный снимок `lab/` остаётся самодостаточным.

Алхимическая лаборатория пока хранится как автономный снимок версии 28 без исходного сборщика; её `lab/assets/` содержит необходимые копии этих же файлов. При переносе алхимии на модульную сборку подключить этот каталог как источник.

Менять текстуры в `metals/` следует с проверкой обеих сцен. Локальные копии в `lab/` обновляются только вместе с новой проверенной сборкой соответствующей сцены.
